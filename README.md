# LQU-driven Heisenberg dimer

Code to reproduce the figures in:

**"General perturbation theory for local quantum uncertainty and its formulation in the linear-response regime"**
A. A. Jimenez-Romero and F. Rojas
Centro de Nanociencias y Nanotecnología, UNAM
*Physical Review A* (accepted, 2026). DOI: [10.1103/9pz4-6v9q](https://doi.org/10.1103/9pz4-6v9q)

## Contents

Each figure has a Python script and an equivalent Jupyter notebook:

- `LQU-fig1.py` / `LQU-fig1.ipynb`
- `LQU-fig2.py` / `LQU-fig2.ipynb`
- `LQU-fig3.py` / `LQU-fig3.ipynb`
- `LQU-fig4.py` / `LQU-fig4.ipynb`

These reproduce the local quantum uncertainty (LQU) results for the isotropic Heisenberg dimer under a periodic driving field, as derived in the paper.

## Requirements

- Python 3.x
- NumPy
- Matplotlib

## Usage

Run any script directly, e.g.:

```bash
python LQU-fig1.py
```

or open the corresponding notebook.
